## 风花雪月移动版
#### 注意
3.0之前的版本不建议更新。
#### ABOUT
- 一个集游戏、视频、动漫、漫画相关一切资源的浏览，搜索，收藏整理的app。
- 正常收录网站： Switch520, IGAME游戏基地,MYCOMIC,flysheep,Koyso,飞极速在线,哈哈影视,策驰影院,电影线上看,AGE动漫,玩Y游戏
- 初衷源于电子ED,找游戏的兴趣越来越大，相反玩游戏的想法却越来越少。既然如此不如做个方便找资源的app。
- 存储价格上涨，存资源不如存链接。立省99%存储空间。
- 立志做到即使原链接过期，只要一个名字，随时都能找到可用资源。
- QQ裙讨论：341591816 验证：HFHXY
#### publish: https://github.com/hke124/HFHXY/releases
### 浏览
- 优化浏览体验，自动加载下一页，支持跳转页面以及保存当前页数功能。
- 优化图片加载，对图片进行三级缓存，不用重复加载，提升浏览速度。
- 集成搜索功能
- 登陆验证（部分网站需要登陆才能完整预览）
- 域名推荐（该网站下的域名集合）。可以通过测速选择最优域名，切换域名同时会修改收藏信息中的相关域名，不用担心域名更换收藏作废。同时还会迁移登陆信息，不用重复登陆。
- 支持漫画阅读。一键提取图片链接，收藏保存分享都可以。
### 收藏
- 可以跟其他浏览器的收藏夹相互导入。
- 跟网页收藏夹相比，增加了图片预览。
- 支持搜索
- 排序。支持自定义排序（正则排序），更方便整理资源。
- 可以编辑tag。支持tag查询。
- 支持一键分享。

#### 快捷方式
- 1.长按桌面图标，可以直接进入搜索，管理等页面。
- 2.应用内点击设置说明->点击自定义返回功能->将上面网站的名称输入进去，中间用,或者换行符。在首页长按返回键执行。
